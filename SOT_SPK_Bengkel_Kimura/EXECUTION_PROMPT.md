# Prompt Eksekusi Awal — Kimura SPK

Bertindak sebagai senior React + Vite front-end engineer yang mengikuti kontrak `AGENTS.md`.

## Konteks
Baca dan patuhi:
- `AGENTS.md`
- `PRD.md`
- `UI-GUIDELINE.md`
- `IMPLEMENTATION_PLAN.md`

Proyek: Sistem Pendukung Keputusan Pemilihan Supplier Sparepart pada Bengkel Kimura Menggunakan Metode SAW Berbasis Web.

## Tugas Pertama
Kerjakan **Step 1 — Bootstrap dan Shell saja** dari `IMPLEMENTATION_PLAN.md`.

### Ketentuan
1. Periksa struktur repository dan `package.json` yang sudah ada sebelum mengubah file.
2. Jika folder belum berisi proyek, siapkan React + Vite dengan JavaScript.
3. Buat shell aplikasi modern bergaya SaaS dengan palet merah, hitam, putih.
4. Buat sidebar/topbar responsif dan navigasi untuk:
   - Dashboard
   - Data Supplier
   - Data Kriteria
   - Bobot Kriteria
   - Penilaian Supplier
   - Perhitungan SAW
   - Hasil Ranking
   - Laporan
5. Buat halaman login sebagai prototype; beri penjelasan bahwa autentikasi belum aman/terhubung backend.
6. Dashboard boleh memakai angka demo, tetapi labeli secara eksplisit sebagai data contoh.
7. Buat setiap menu dapat dinavigasi. Untuk halaman yang belum diimplementasikan, tampilkan placeholder yang rapi dan jujur; jangan berpura-pura fitur lengkap.
8. Jangan mengimplementasikan CRUD, mesin SAW, backend, database, atau fitur Step 2+ pada tahap ini.
9. Hindari dependensi tambahan kecuali diperlukan. Jika perlu menambah dependensi, jelaskan alasannya.
10. Jalankan pemeriksaan build yang tersedia dan laporkan hasilnya secara akurat.

## Output Setelah Selesai
- Daftar file dibuat/diubah.
- Ringkasan implementasi.
- Perintah untuk menjalankan proyek.
- Hasil build/lint yang benar-benar dijalankan.
- Hal yang belum dikerjakan.
- Minta persetujuan sebelum melanjutkan ke Step 2.

Mulai dengan memeriksa repository, lalu kerjakan Step 1 saja. Jangan lanjut ke tahap lain tanpa persetujuan pengguna.
